# Urban Flow

## Sprint actual: Sprint 3

### Objetivo
Persistir los datos procesados en una base relacional con SQLAlchemy,
versionar los binarios con DVC y habilitar la busqueda de patentes por
imagen mediante una base vectorial (ChromaDB + OpenCLIP).

### Introduccion y contexto
El sistema crecio en volumen y complejidad, por lo que se migra de archivos
CSV a una base de datos estructurada con control de versiones de datos.
